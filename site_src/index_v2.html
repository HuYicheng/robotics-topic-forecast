Robotics Topic Forecast

Which topics will grow or shrink in robotics papers in 2027? The forecast covers robotics' own topics (manipulation, humanoids, VLA, sim-to-real…) and ML / vision topics as robotics uses them. It combines six signals, from robotics' own curves to what ML and vision venues publish about robots, and each signal was tested on 2024–2026 before being used.
